# Docker Action

Docker based github action.

## Inputs

| Name    | Description        | Mandatory | Default |
|---------|--------------------|-----------|---------|
| message | Message to display | Yes       | -       |

## Outputs

| Name           | Description                     |
|----------------|---------------------------------|
| output-message | Message generated by the action |

## Example

```yaml
name: Workflow example
on:
  push:
    branches:
      - main

jobs:
  message-job:
    runs-on: ubuntu-latest
    steps:
    - name: Checkout code
      uses: actions/checkout@v4

    - name: Run docker action
      uses: ./
      with:
        message: "Hello from docker action"
```
